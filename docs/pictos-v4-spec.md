# KINQ — collection 04

Direction : le minimum de traits pour reconnaître un objet. Référence visuelle : la bande de pictogrammes fournie par le client le 24 septembre 2026.

- Grille 24 × 24 ; trait 1,5 ; terminaisons et angles arrondis.
- Une seule encre : vert acide `#b2ff1a` sur noir `#111310`, noir sur gris `#dfe2dc` ou vert acide.
- Aucun reflet, ombre, texture, modelé ou détail décoratif.
- Taille courante 48 px ; contrôle dans l’atelier à 24, 32, 48 et 80 px.
- Garder le libellé visible : certaines catégories abstraites ne possèdent pas de symbole universel.
- 74 catégories conservées de la maquette et un harnais supplémentaire. Chaque ID reste stable.

Casquette pour Leather, os pour Pup play, menottes pour restraints, cadenas pour Chastity, croix pour Medical, goutte pour Watersports. Les catégories proches gardent un signe distinct lorsque possible ; le nom précise les différences.

Les SVG sont transparents et vectoriels. Les exports depuis l’atelier figent l’encre choisie. Les fichiers sources utilisent la variable `--ink` ; les SVG individuels du ZIP définissent cette variable. Pour le sprite, définir `--ink` sur le SVG appelant.

Génération : `python3 scripts/build-pictos.py`. Dessins : `scripts/pictos_v4.py`.
